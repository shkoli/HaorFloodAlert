\# HaorFloodAlert



\*\*Haor-specific Real-Time Flood Prediction \& SMS Alert System\*\*  

for Sunamganj, Bangladesh



\*\*Author:\*\* Salma Hoque  

\*\*Date:\*\* February 2026  



\*\*Tech Stack\*\*  

\- Sentinel-1/2 + Google Earth Engine  

\- RF + XGBoost + LSTM Ensemble  

\- Streamlit Dashboard  

\- Twilio SMS Alert  



\*\*How to Run\*\*  

1\. pip install -r requirements.txt  

2\. streamlit run streamlit\_app/app.py
